# Goal-Conditioned Multi-Agent Cooperation with Contrastive RL
Codebase for Goal-Conditioned Multi-Agent Cooperation with Contrastive RL paper.

## Setup Instructions
Clone the repository. Install conda environment with ``conda env create -f conda_env/environment.yml``

## Running
``conda activate gcmarl``

``python train_icrl_smax.py``
